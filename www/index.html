A webserver is a software system designed to handle and respond to client requests over the web. It listens for HTTP requests from browsers or other clients and delivers web content such as HTML pages, files, or dynamic responses generated by scripts.

Our custom-built C++ webserver supports essential HTTP methods, facilitates running CGI scripts for dynamic content, and includes an auto-indexing feature that generates directory listings automatically.

Core Functionalities

  • Handles HTTP methods: GET, POST, DELETE, and more
  • Supports execution of CGI scripts for dynamic responses
  • Includes auto-indexing to display directory contents automatically
  • Efficient request processing and serving of static and dynamic content
